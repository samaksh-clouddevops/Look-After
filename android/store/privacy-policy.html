Look After Privacy Policy

Last updated: 2026-08-10

Look After (“the App”) is a calm executive layer for planning days, medications, focus sessions, health trends, and optional life modules. We design for local-first use: core data stays on your device unless you opt into cloud features.

Data we process on device

  • Tasks, notes, tags, areas/projects, planning conversations, and coach history
  • Medications and adherence marks you enter
  • Focus / body-double session state and optional ambient preferences
  • Optional Health Connect metrics (sleep, steps, heart rate, energy) when you grant access
  • Optional calendar events when you grant READ_CALENDAR
  • Optional camera frames for body-double preview (not uploaded by default)
  • Optional module data: travel trips/packing, cycle logs (opt-in), learning cards, creativity sparks, habits
  • Notification and quiet-hours preferences, onboarding state

Optional cloud services

  • LLM coach / planner — only if you configure an API key; prompts may include task titles, board summaries, and health/capacity context
  • Firebase Auth / Firestore / Crashlytics — only when a google-services.json is shipped; then account ids, sync payloads, room signaling, and crash stacks may leave the device
  • WebRTC body-double — media may go peer-to-peer via STUN/TURN you configure; signaling may use local files or Firestore when enabled

Permissions

Notifications, calendar, camera, microphone (optional), Health Connect, and Do Not Disturb access are requested only for features you use. You can deny any permission; the rest of the App keeps working.

Children

The App is not directed at children under 13. Medication and cycle tools are adult self-care utilities.

Your choices

  • Export / import backup from Privacy & data
  • Factory reset clears local stores (tasks, modules, prefs)
  • Turn off cycle tracking, notifications, or Health Connect anytime
  • Uninstall removes on-device data
  • For Firebase projects you control, delete the user in the Firebase console
