# Look After 0.1.0-alpha

**Release date:** August 9, 2026  
**Codename:** First Alpha  
**Git tag:** `v0.1.0-alpha`

Look After is an AI-powered executive function companion for iOS (macOS and Widget extensions included). This is the **first public alpha** — suitable for internal testing and early adopters, not production App Store release.

## Highlights

### Proactive AI (Phase 2)
- Moment-aware nudges: transition shields, wake recovery, week primer, end-of-day close
- Action bundles with unified `ProactiveActionRouter` (banner + notification handling)
- Feedback, dismiss, and snooze persistence so the system learns what helps
- Proactive speech and accountability body-doubling share sheet
- Initiation-bridge tuning (debounced foreground tracking, reduced repeat nags)

### Licensed cloud AI (no keys on device)
- Azure Container App auth-proxy for GLM chat and OpenAI TTS
- Product-key licensing via Settings → License
- Proxy-only AI routing — client API key settings removed

### Scheduling & capture
- Timeline drag-to-reschedule with time meter
- Capture composer and intent router (task, journal, inbox)
- Contextual day replan sheets (post-wake, going out, calendar change preview)
- SQLite-backed task persistence

### Platform
- Live Activities + Widget shortcuts
- Health connection status banner and manual sleep logging
- Weekly Review debrief with AI retrospective
- Personal Team dev signing (Sign in with Apple in production entitlements only)

## Requirements

- **iOS 26+ / macOS 26+** for current trunk (Liquid Glass revamp). Historical alpha builds may have targeted iOS 17 — see git tag `v0.1.0-alpha`.
- Xcode 26+ (iOS 26 SDK)
- Firebase `GoogleService-Info.plist` (see `Config/GoogleService-Info.plist.example`)
- Product key for licensed AI (mint via auth-proxy admin API)

## Known alpha limitations

- Firebase project uses mock/dummy config for local dev (`lifeos-dummy`)
- License redemptions and auth-proxy license state are ephemeral on cold start (no Azure Storage yet)
- `AUTH_DEV_ALLOW_INSECURE=true` on Container App — replace before production
- OpenAI TTS requires real `OPENAI_API_KEY` on Container App
- Sign in with Apple requires paid Apple Developer Program + production entitlements file
