Look After Privacy Policy

Last updated: 2026-08-07

Look After (“the App”) helps you plan days, track medications, and run focus sessions. We design for local-first use.

Data we process on device

  • Tasks, notes, medications, focus sessions, onboarding preferences
  • Optional Health Connect metrics (sleep, steps, heart rate) when you grant access
  • Optional calendar events when you grant READ_CALENDAR
  • Optional camera frames for the body-double mirror (preview only; not uploaded by default)

Optional cloud services

  • LLM coach/planner — if you set an API key, prompts may include task titles and health readiness summaries
  • Firebase Auth / Firestore / Crashlytics — only when you ship google-services.json; then account ids, sync payloads, and crash stacks may leave the device

Permissions

Notifications, calendar, camera, Health Connect, and DND access are requested only for the features you use. You can deny any permission.

Children

The App is not directed at children under 13.

Your choices

Uninstall clears local data. Disable sync/LLM in settings. For Firebase projects you control, delete the user in the Firebase console.
